# Agentic Engineering Hackathon

The goal of this hackathon is to become more familiar with agentic engineering: understand its concepts, practise applying them, and use Codex to solve given tasks. The sample application provides a shared exercise for that learning.

By the end, you should be able to explain the concepts in your own words, apply them to a task, and guide Codex through a solution you can check and review. You do not need to be an expert in the application stack.

## Tools to have ready

### Required

- **Visual Studio Code — latest stable release.** The primary IDE for editing, reviewing, and debugging code.
- **C# Dev Kit extension for Visual Studio Code — latest stable release.** For working with the .NET backend.
- **PostgreSQL extension for Visual Studio Code, published by Microsoft — latest stable release.** For inspecting the database and running SQL queries.
- **Codex desktop app — latest stable release.** Used throughout the demonstrations and exercises.
- **.NET 10 SDK — latest available 10.0.x SDK.** For building, running, and testing the backend. Install the SDK, not just the runtime.
- **Node.js — current LTS release, including npm.** For the React and TypeScript frontend.
- **Git — latest stable release.** For local version control and working with repositories.
- **PostgreSQL — current stable release installed locally in container, or access to a database provided for the hackathon.** Ensure you have working connection details and permission to create the application’s tables.

React, TypeScript, and other application dependencies are installed as part of the project setup; separate global installations are not required.

### Optional

- **Docker Desktop — latest stable release.** If you prefer running PostgreSQL in a container.
- **.NET Aspire tooling — a stable release compatible with .NET 10.** For exploring application orchestration.

The sample application and core exercises run without Docker or .NET Aspire.
